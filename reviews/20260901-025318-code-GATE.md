## Non-blocking observations, and what was done about them

`glm` recorded six observations explicitly *not* filed as objections; `kimi`
recorded none beyond noting that some repository-read facts sit outside the
supplied evidence list, which is the same ground as observation 6. Two were
acted on anyway; the rest are recorded here so the disposition is on the record
rather than in someone's judgement.

1. **`grep -oc` is a nonstandard flag pair — `-c` overrides `-o`.** Correct, and
   the card should not publish a confused command even when the printed result
   is unaffected. **Fixed:** the card now reads `grep -c BETA`. Re-measured on
   the served landing chunk: `grep -c BETA` → `0` and `grep -oc BETA` → `0`, so
   the published figure was right either way; the command was the defect.
2. **`/api/health` answering `200` was not in the evidence list given to
   reviewers.** A fair catch on the *log*, not on the claim: the builder did
   measure it in the same batch, at 02:40:51 UTC —
   `{"status":"ok","service":"pumasi-sign","time":"2026-09-01T02:40:51.300Z"}`.
   The measurement is recorded here so the log matches the card. No text change
   was needed; the card already carries the date and the past tense.
3. **Placement of the three `Apache-2.0` strings** (hero strip, stage banner,
   comparison row). Verified directly by the builder against the served chunk,
   not inferred: the three occurrences were extracted with their surrounding
   context, and the comparison row's neighbouring cells read
   `Proprietary Closed Source`.
4. **"shipped cited and dated" for the competitor pricing.** Verified: the
   served landing chunk contains `ecom.docusign.com/plans-and-pricing/esignature`
   and `signwell.com/pricing/`.
5. **"no user has ever seen a `BETA` badge"** — the chunk's only home was
   `LandingView.vue`, whose first deploy is 2026-09-01 01:02:16 UTC and which
   ships `BETA` × 0. The card confines the sentence to that page in the same
   breath.
6. **Hash-attributed repository readings** (`3edd06f`, `0e26917`, `2471a29`,
   `2ab3a4f`). All read from the remote via `gh api`, not from a local checkout
   that could be stale; `2471a29`'s file list was confirmed to include
   `service/src/worker.ts`, `service/src/durable.ts` and `service/wrangler.jsonc`,
   which is what supports "the repository is ahead of the deployment once more".
